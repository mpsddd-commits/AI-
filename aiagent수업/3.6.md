1️⃣ 리스트 방식 (List)
예: 지금 날짜 부분
week_links = ["1157", "1156", "1155"]
options = [
"02월 23일 ~ 03월 01일",
"02월 16일 ~ 02월 22일",
"02월 09일 ~ 02월 15일"
]
사용 방식
week_no = week_links[options.index(selected)]
즉
options index = week_links index
구조
index
 0 → 02월23일~03월01일 → 1157
 1 → 02월16일~02월22일 → 1156
 2 → 02월09일~02월15일 → 1155
리스트 방식 장점 👍

1️⃣ 구조가 단순
["A","B","C"]

2️⃣ 순서가 중요할 때 좋음
예
1위
2위
3위

3️⃣ 반복문 처리 쉬움
for item in list:
리스트 방식 단점 ❌

1️⃣ 서로 다른 데이터 연결이 어려움
지금처럼
options
week_links
두 개를 index로 맞춰야 함

2️⃣ 데이터 추가 시 오류 위험

예
options 10개
week_links 9개
→ index 오류

3️⃣ 코드 가독성 떨어짐

week_links[options.index(selected)]
직관적이지 않음

2️⃣ 딕셔너리 방식 (Dictionary)

지금 코드에서 카테고리 부분
category_map = {
    "국내도서": "001",
    "외국도서": "002",
    "eBook": "017&eBookTp=0"
}
사용
category_no = category_map.get(category)
구조
key → value
국내도서 → 001
외국도서 → 002
eBook → 017
딕셔너리 장점 👍

1️⃣ key로 바로 찾기
category_map["국내도서"]
→ "001"
속도도 빠름 ⚡

2️⃣ 데이터 관계 표현이 명확

카테고리 → 번호
바로 이해됨

3️⃣ index 오류 없음

리스트처럼
index mismatch
문제가 없음

4️⃣ 검색 속도 빠름

시간 복잡도
list : O(n)
dict : O(1)
딕셔너리 단점 ❌

1️⃣ 순서 관리 어려움

파이썬 3.7 이후 순서 유지되지만
원래 목적은 아님

2️⃣ 동일 key 불가능

{
"A":1,
"A":2  # 불가능
}

week_map = {

4️⃣ 정리 (실무 기준)
방식	사용 상황
list	순서 데이터
dict	key-value 매핑
예시

list
랭킹
top10
dict
카테고리 → 코드
날짜 → weekNo

1️⃣ dict으로도 Top10 가능은 함

예를 들어
top10 = {
    1: "책A",
    2: "책B",
    3: "책C",
    4: "책D"
}
사용

print(top10[1])   # 1위 책
또는 반복
for rank, book in top10.items():
    print(rank, book)
출력

1 책A
2 책B
3 책C
4 책D

즉 순위 key로 사용하면 가능합니다.

2️⃣ 하지만 실무에서는 리스트를 더 많이 사용

Top10 데이터는 보통 이렇게 저장합니다.
top10 = [
    {"rank":1, "title":"책A"},
    {"rank":2, "title":"책B"},
    {"rank":3, "title":"책C"}
]
이유는 데이터 처리하기 훨씬 편하기 때문입니다.
예
for book in top10:
    print(book["title"])

3️⃣ 크롤링 데이터에서는 리스트가 표준
지금 코드도 이미 좋은 방식입니다.
books.append({
    "title": title,
    "author": author,
    "star": star,
    "sale_num": sale_num
})
이렇게 하면
df = pd.DataFrame(books)
바로 DataFrame 만들 수 있습니다.

4️⃣ dict로 만들면 오히려 불편해짐

예
books = {
1: {"title":"책A"},
2: {"title":"책B"},
3: {"title":"책C"}
}
이러면
pd.DataFrame(books)
구조가 깨집니다.
그래서 보통
크롤링 → list
설정값 → dict
이렇게 나눕니다.

5️⃣ 지금 코드 기준으로 정리
데이터	구조
카테고리	dict
주차	dict
책 데이터	list
차트	list → DataFrame
